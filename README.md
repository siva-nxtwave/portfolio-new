# Karthikeyan A — Software Developer Portfolio

A modern, high-performance developer portfolio built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Three.js (React Three Fiber)**.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), Custom Glassmorphism & Modern CSS Variables
- **Animations & 3D**: [Framer Motion](https://www.framer.com/motion/), [Three.js](https://threejs.org/) / [@react-three/fiber](https://r3f.docs.pmnd.rs/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/), [Zod](https://zod.dev/)
- **Theme**: [next-themes](https://github.com/pacocoursey/next-themes) (Dark/Light mode support)

## ✨ Features & Sections

- **Interactive 3D Hero Scene**: Optimized WebGL canvas with viewport intersection observer (automatically pauses rendering when out of view for 60/120 FPS scrolling performance).
- **Trusted Technologies Marquee**: Dynamic infinite scroll featuring core technologies (Python, JavaScript, React, React Native, Node.js, Express.js, Google Gemini API, SQL).
- **About & Professional Background**: Comprehensive career narrative detailing transition from Royal Enfield procurement operations, B.Sc. Physics degree, and NxtWave full-stack development.
- **Interactive Skills Matrix**: Categorized proficiency grid with animated level meters across Languages, Frontend, Backend, AI Integration, and Platforms.
- **Projects Showcase & Case Studies**:
  - **ResumeIQ AI**: Full-stack AI resume analyzer powered by Google Gemini API, Express.js, and Multer.
  - **Space Escape Runner**: Interactive 2D mobile arcade game built with React Native and Expo.
- **Career & Education Timeline**: Structured milestones covering Royal Enfield, NxtWave, and H.H. The Rajah's College.
- **Verified Certifications**: Interactive credentials view with direct verification links.
- **Contact & Direct Messaging**: Form validation with Zod, celebratory confetti animation, and one-click copy for email and phone.

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/karthikeyan-portfolio.git
   cd karthikeyan-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser.

4. **Build for production**:
   ```bash
   npm run build
   npm run start
   ```

## 🌐 Deploy to Vercel

The easiest way to deploy this portfolio is using [Vercel](https://vercel.com/):
